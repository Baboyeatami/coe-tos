# Evidence-led assessment mapping

## Authority order

1. Actual question/task and its published scoring breakdown.
2. Published learning outcomes and instructional coverage.
3. Institutional TOS categories and cognitive-band policy.
4. Requested target allocation and proposed design choices.

A target band is a design constraint, not evidence that a task assesses that
level. When levels and bands conflict, report both and propose real changes.

## Cognitive demand

Classify the performance that earns credit, considering the task, context and
rubric together. Verbs alone are insufficient.

- **Remembering:** retrieve, identify or reproduce knowledge when recall is the
  explicitly scored demand. Knowing a formula while using it is not a second,
  independent recall score.
- **Understanding / application:** explain meaning or carry out a taught procedure
  when these are combined by the institution. Do not universally equate the
  full Bloom taxonomy with the CJC three-group layout.
- **Thinking:** analyze evidence, compare behavior, justify choices, synthesize
  a design, evaluate limitations or create a justified solution.

Examples: substituting a result into a supplied equation can be application;
judging an unexpected residual and defending a corrective strategy can be
analysis. A video format itself does not make an explanation higher-order.

## Preserve the full scoring hierarchy

Question -> criterion -> published subcriterion -> allocation -> topic/group.

Split marks only when the source supports the split, or clearly label the split
as a proposal needing adoption. If a single published 4-point subcriterion
spans several topics, its allocation rows together must still sum to 4.
Shared written/video tasks support multiple methods; they must not be counted
at full value again for every method. Equal attribution can explain content
coverage without changing the rubric or number of questions.

## Examples versus existing exams

The bundled example intentionally proposes 16/24/60 and explicitly scores
recall. It is not evidence that an arbitrary numerical-methods examination
has those levels. The earlier course workflow inspired the template handling,
but its hard-coded score reclassification is not copied as a universal rule.

If a source has 5 verification + 3 convergence points, retain 5/3. If it scores
procedure narration, do not describe that score as critique/comparison unless
the question and rubric actually require it. Arithmetic tests cannot discover
these semantic mismatches on their own; the agent's source review is essential.
